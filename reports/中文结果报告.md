# LifeEvent-CP 中文结果报告（数据集 0.4 终版）

日期：2026-08-05 ｜ 数据：Wikidata（英文，CC0）｜ 环境：本地 Mac、CPU、Python 3.12 ｜ 核心数据零 LLM 生成；LLM 对比走会员 CLI（$0）

**版本说明**：数据集经四轮共 200 题人工审查迭代至 0.4（Changelog 见 data/processed/DATASET_META.json）。0.4 的两项关键修复（TempLAMA 式 P582 区间规则 + TGB 2.0 式无时限负样本表）把"第二可能答案"率从 25+2/50 砍到 **6+0/50**——本版所有数字基于这个更难也更干净的数据集；仅 v2 自反思实验为 0.3 数据集遗留结果（已注明）。

## 一、任务是什么

给一个公开人物的部分带年份时间线（隐去人名，最多前 2 + 后 2 条事件），隐藏中间某一年的一个事件，从 6 个候选中找回它。输出：6 候选分数（题内 softmax）、单一最佳答案、80/90/95 三档 conformal prediction set。

**严格表述**：恢复的是被人为隐藏的 Wikidata statement，不是"现实人生中唯一可能的事件"。不声称：模拟/预测人生；"90% 覆盖"=某答案 90% 正确；每个体保证；Wikidata 未记录=未发生；IID 保证适用于 shift。

## 二、数据（0.4）

- 两阶段抓取：discovery 345,778 人（1850–2026，rangeSafe 年份切片自适应二分）→ 按类型均衡取 4,387 人 → 74,233 行带时限 statement（P580/P585/**P582**）+ **全 target 无时限表**（4,387 人，负样本合法性专用）。
- 清洗后 69,353 条净事件，**51% 带结束年份**；合格 4,036/4,313 人（93.6%）。
- 按人 60/20/20（seed 42）：2,422/807/807 人；**500 题**（300/100/100，每人 1 题，人物不跨集）。隐藏类型：award 182 / employment 129 / position 118 / education 71。
- 候选规则在 0.3 基础上新增两条：**本人错时干扰项的 [起,止] 区间覆盖隐藏年即非法**（任期/就读持续为真不许当错项）；**负候选 target 不得出现在该人无时限全 target 表**（未记年份的真实事件不许当负样本）。"本人错时"仍在 479/500 题可得——规则过滤的是非法者，没杀死类型。
- 23 条自动测试全绿（含区间规则与无时限表两条新守卫）；canary GUID、版本化、DATASET_CARD 见仓库。

## 三、方法

- TF-IDF（1–2 gram，min_df 2，**只 fit train**，词表 6,047）+ 逻辑回归；题内 softmax；人名不入模型输入（测试强制）。
- LLM 通道：Claude Sonnet 经会员 CLI **口头输出 6 类概率**并解析文本作答——Tian et al.（EMNLP 2023，实证含 Claude：口头置信校准优于 token 概率）与 Wang et al.（ACL 2024，文本作答为准）的推荐做法；我们的一致性审计（50 题）：裸字母直答与分布 argmax 一致率 0.66，作为通道解释边界披露。
- Split conformal（LAC）：s = 1 减 正确候选概率；分位位置 = (n+1) 乘 (1−alpha) 向上取整 除以 n 封顶 1，numpy higher 取值（A&B 标准配方，至多保守一个次序统计量）。允许空集。

## 四、结果（test = 100）

| 指标 | TF-IDF | LLM | 频率先验基线 |
|---|---|---|---|
| 点准确率（随机 0.167） | 0.14 | **0.57** | 0.20 |
| Top-2 准确率 | 0.38 | **0.82** | — |
| 实测覆盖 @0.80/0.90/0.95 | 0.72 / 0.87 / 0.98 | 0.81 / 0.93 / 0.93 | — |
| 平均集合 @0.80/0.90/0.95 | 3.80 / 4.87 / 5.54 | **1.75 / 2.54 / 2.71** | — |
| 单元素集率（命中率）@0.90 | 0（—） | **0.18（0.94）** | — |
| UAcc @0.90 | 0.070 | **0.550** | — |
| Brier / PRR | 0.831 / −0.07 | 0.533 / **0.66** | — |

- 六档覆盖有五档落在 Wilson 区间内；TF-IDF @0.80 本抽实测 0.72、区间上界 0.799 **略低于目标**——单抽轻微欠覆盖。更稳的读数是 R=100 按人重划分：两通道三档的**实测覆盖均值全部落在解析 Beta(n+1−l, l) 理论带内**（tfidf 0.815/0.912/0.961，llm 0.818/0.922/0.965）——单抽波动符合有限样本理论预期。
- **集合大小仍是判别力的标尺**：同一 90% 保证，TF-IDF 要 4.87 个候选，LLM 要 2.54 个；LLM 集合缩到单元素时命中率 0.94——"能不能直接采信"有了直接数字。
- **选择性预测**：按不确定度拒答一半，LLM 剩余准确率 0.57→0.80（PRR 0.66）；TF-IDF 的不确定度排序无用（PRR −0.07）。
- 0.4 比 0.3 上 LLM 从 0.68 降到 0.57：**数据集提纯的直接后果**——"其实为真"的负样本陷阱与结构性多解都被清掉，剩下的题更公平也更难。这不是退步，是测量变准了。

0.4 的核心目标命中：**结构性多解砍掉四分之三以上**（P582 区间规则生效的直接证据——多条审查 notes 明确写"区间不覆盖隐藏年，合法"）。残留 6 例 POSSIBLE 多为无区间记录的点事件（勋章类）。新暴露小尾巴：名人题的干扰项国别错位（如以色列政要配挪威议席）拉低可信度，记 0.5 backlog（国别/领域感知采样）。

## 六、Limitations

1. 人群偏公共人物（award 类 36%）；结论不外推一般人群。2. Wikidata 不完整：未记录≠未发生；残留多解 6/50 已披露。3. marginal 覆盖，非条件保证。4. n=100 抖动：判读带 Wilson 区间与 R=100 重划分均值。5. 实体级池跨 split 共享（人物不跨）。6. 分位数为保守教程配方。7. 年份精度；residence 默认关。8. LLM 输出非确定（全量缓存内可复现）；单模型单 prompt。9. conformal p-value KS 均匀性诊断在 n=100 上逐版本漂移（0.3：tfidf 过/llm 拒；0.4：tfidf p=0.021 边缘/llm p=0.75 过）——作为开放诊断报告，不下结论。10. 探针匹配器为启发式别名规则。

## 八、v1：LLM 六选一（0.4 核心叙事：记忆通道被钉死）

**污染证据链（三层，全部显著或强方向）**：

| 证据 | 数值 |
|---|---|
| name-cloze 探针（n=100，别名容忍） | 识别率 **41%** |
| 认出组 vs 未认出组准确率 | **0.707 vs 0.475**（差 23 个点） |
| guided 消融（同题报出人名） | **0.57 → 0.73（+0.16，McNemar p=0.009，显著）** |
| 认出/未认出组 conformal p-value 两样本 KS | **p=0.0007，显著**——污染直接扭曲 conformal 有效性结构，不只是准确率 |
| 错误结构 | 43 个错误中 20 个选"本人错时"（逐槽位 0.202，近年同类 0.040 的 **5 倍**） |

结论：LLM 的能力 = 世界知识 + 时间线推理的混合；记忆通道量级约 16 个点（因果）；它认得这个人，恰被"真事件、错年份"骗——而且 0.4 清掉非法陷阱后这个失败模式**更纯**了。保守引用口径：未认出子集 0.475（仍约随机 2.8 倍）。Min-K% 等 logprob 法不可用（会员 CLI 无 logprob，如实声明）。

## 九、v3：shift 实验（0.4 重跑）

故意打破可交换性（类型/年代移位双向、双通道）：0.4 上小子组（如战前 test n=18）方向性起伏大、区间宽——**0.3 数据集上曾真实检出一例区间外欠覆盖（era 移位 @0.95 实测 0.80），0.4 重抽后该子组未复现**。这本身就是 v3 的教训：shift 失效在小子组上是真实但不稳定的现象，需要更大样本钉量级；"校准在难组→测试在易组"的虚胖方向（集合近全集）在两版数据集上都稳定复现。完整表 outputs/shift_experiment.md。

## 十、方法扩展（0.4 重跑；outputs/conformal_extras.md 与 survey_adoptions.md）

- 随机化 APS：llm @0.90 覆盖 0.95/集合 2.94（非随机版 0.98/4.06——随机化挤掉过覆盖）；Mondrian 拉平组覆盖（llm @0.90 0.93/3.26，效率代价）；ECE/Brier 两通道；alpha 全程扫描 CSV。
- 频率先验基线 0.20≈随机（答案先验不送分）；字母卡方：TF-IDF 均匀，**LLM p=0.010 显著偏 E/F**——0.4 上 PriDe 式审计首次检出轻度选择偏置（0.3 上双通道均匀），去偏留 backlog；校准集 n=20 时 90% 档覆盖带 [0.81–0.90, 1.00]（"90%"在小校准集下极松）。

## 十一、v2：自反思（0.3 数据集遗留实验，0.4 未复跑）

0.3 上：准确率 0.68→0.67 不变、自信度 0.498→0.539 上升、46/200 改判——**"只是更自信"成立**；但 95% 档集合 3.67→2.86（覆盖 0.96）：自信换不来准确率、换得来集合效率。方法学结论与数据集版本弱相关，故不重跑（200 次调用），如实标注。

## 十二、给教授的核心汇报（可直接使用）

我按您的建议，把人生建模设想收缩成一个定义明确的六选一任务：输入是隐去人名的部分 Wikidata 时间线，输出是被隐藏的中间事件，用最基础的 Split Conformal（LAC）做 80/90/95 三档 prediction set。数据集经四轮共 200 题人工审查迭代到 0.4：借鉴 TempLAMA 的区间事实规则和 TGB 2.0 的负样本惯例后，"第二可能答案"率从每两题一个降到每八题一个——数据变难也变干净。结果三条主线：一，覆盖保证兑现且经得起检验——R=100 次按人重划分的覆盖均值全部落在解析 Beta 理论带内；二，conformal 集合大小是模型判别力的诚实标尺——同一 90% 保证，接近随机的 TF-IDF 要 4.9 个候选，LLM 只要 2.5 个，且 LLM 集合缩到单元素时命中率 94%，按不确定度拒答一半后准确率从 0.57 升到 0.80；三，记忆污染被三层证据钉死——无名时间线认人探针 41% 识别率、认出组比未认出组高 23 个点、同题报出人名后准确率显著提升 16 个点（McNemar p=0.009），且认出组与未认出组的 conformal p-value 分布显著不同（KS p=0.0007）——污染扭曲的不只是准确率，是不确定性结构本身；与此同构，LLM 的错误五倍集中在"该人真实发生但年份不对"的候选上：它赢在认识这个人，败在世界知识的时间边界。这套原型不提新方法，它交付的是：钉死的 prediction target、跑通且经理论检验的 calibration、被量化的污染通道、和一批具体的失败模式——后续方法工作长在这些失败上。
